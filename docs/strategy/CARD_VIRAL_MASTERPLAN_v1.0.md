## Part 0 — 지금까지 놓쳤던 것 (정직한 진단)

카드 "디자인 tweak"만 조각조각 봐서 **시스템 차원 5가지를 놓쳤습니다**:

| 놓친 것 | 왜 치명적 |
|---------|----------|
| **1. 측정 루프 없음** | 쇼츠는 Analytics로 최적화했는데, 카드는 **저장·팔로우·도달을 측정할 방법이 전혀 없음** → 계속 장님 최적화 |
| **2. 플랫폼별 전략 미분화** | Pinterest(검색/SEO) vs Instagram(피드/DM공유)는 **완전히 다른 메커니즘**인데 똑같이 취급 |
| **3. 콜드스타트 오판** | 팔로워 0인데, **Pinterest는 검색 기반이라 팔로워 없이도 성장 가능** — 이걸 최우선으로 안 잡음 |
| **4. 프로필/니치** | 팔로우 전환은 게시물뿐 아니라 **프로필·바이오·니치 명확성**이 좌우 |
| **5. 토픽-마켓 핏 미검증** | V1/V2/V3 중 뭐가 반응하는지 안 봄 |

→ 이번 마스터플랜은 **디자인 + 시스템**을 함께 다룬다.

## Part 1 — 성장 퍼널 (전체 그림)

```
[노출]  → [1·2슬라이드 훅]  → [스와이프 완주]  → [저장/공유]  → [팔로우]  → [링크 클릭]
 SEO/       스크롤 정지         8~10장·정보공개    최강 신호      프로필·시리즈   수익
 탐색                          (사진·정보)
```
각 단계에서 이탈하면 다음이 없다. **현재 카드는 "훅~완주"만 신경 썼고, 노출(SEO)·저장/공유/팔로우 유도가 약함.**

## Part 2 — 플랫폼별 전략 (가장 크게 놓쳤던 부분)

| 항목 | **Pinterest** | **Instagram** | **TikTok** |
|------|--------------|--------------|-----------|
| 발견 방식 | **검색(SEO)** · 관련핀 | 피드·탐색·해시태그 | FYP·사운드 |
| 팔로워 필요? | ❌ **불필요**(검색) | ⚠️ 일부 필요 | ⚠️ |
| 콜드스타트(0팔로워) | ✅ **최적** | 느림 | 중간 |
| 수명 | **수개월~년(에버그린)** | 며칠 | 며칠 |
| 핵심 레버 | **롱테일 키워드·저장·꾸준함** | 훅·DM공유·4:5·2번슬라이드 | 훅·사운드 |
| 최적화 핵심 | 제목·설명 **키워드**(해시태그 X) | 첫슬라이드·SEND(DM) | 첫프레임 |

### 검증된 핵심 사실
```
· Pinterest = 시각 검색엔진(4.98억). 발견은 팔로워 아닌 '검색'. 저장·클릭이 신호. 핀은 에버그린.
· 캐러셀 = 최고 참여(1.92% vs 릴스 0.50%), 정적 1.4배 도달. 8~10장 최적.
· IG 최적 = 4:5(1080×1350). 저장 22%↑. SEND(DM공유)=신규도달 최강 신호(Mosseri).
· 안 넘겨도 2번 슬라이드 재노출 → 1·2 둘 다 훅.
```

### → 전략적 결론
**팔로워 0 → Pinterest가 콜드스타트 엔진** (검색 기반, 에버그린, 팔로워 불필요).
지금 수동 게시 가능한 것도 Pinterest. **Pinterest를 1순위로, SEO 중심 최적화.**

## Part 3 — 최종 작업 계획 (단계별)

### 🔹 Phase 0 — 측정 기반 구축 (없으면 계속 장님)
```
· 결과 추적 체계: 게시물별 저장·클릭·팔로우·노출 기록
  - Pinterest 승인 후: Pinterest Analytics API로 자동 수집 (pin 저장·노출·클릭·아웃바운드)
  - 승인 전: 수동 기록 시트(간단) — 어떤 카드가 저장되나 관찰
· 쇼츠에서 배운 교훈: 측정 없이는 최적화 불가
```

### 🔹 Phase 1 — 콘텐츠 품질 (스크롤 정지 + 저장 가치)
```
1. 슬라이드 8~10장 (현재 6~8 → 확장, 완주율 반등 구간)
2. Instagram 4:5(1080×1350) (현재 1:1 → 화면 손해 해소)
3. 훅 강화: 큰 숫자 + 호기심 갭 + 실사진 배경
4. 1·2 슬라이드 둘 다 훅 (2번 재노출 대응)
5. 실제 사진 전 슬라이드 (Unsplash 폴백 강화 — 지명+지형 재검색)
6. 레이아웃 폴리시: CTA 세로 여백 해소, 형광펜 위치·전체적용, 진행도트(1/8)
```

### 🔹 Phase 2 — 성장 신호 (저장·공유·팔로우 명시 유도)
```
7. SAVE CTA 강조 "여행 위해 저장" (저장 22%↑)
8. SEND(DM) CTA 강조 "친구에게 보내요" (신규도달 최강 신호)
9. FOLLOW 트리거 추가 "매일 숨은 발견 — 팔로우" ← 현재 완전 부재!
10. 댓글 유발 질문 (쇼츠 학습: 2초 답 구체질문)
11. 저장 가치 심화: 슬라이드마다 예산·시즌·이동법 구체 정보
```

### 🔹 Phase 3 — 플랫폼별 배포 최적화
```
12. Pinterest SEO (콜드스타트 엔진) ← 최우선
    · 롱테일 키워드 제목/설명 ("hidden coastal towns in japan under $50")
    · 보드명·설명도 키워드
    · 해시태그 아닌 자연어 키워드 (Pinterest는 검색)
13. Instagram: 4:5 + DM공유 유도 + 해시태그 + 2번슬라이드 훅
14. 프로필/바이오 최적화 (팔로우 전환): 명확한 니치·가치 제안·고정 소개
```

### 🔹 Phase 4 — 측정·반복 (복리)
```
15. 어떤 토픽(V1/V2/V3)·훅이 저장·팔로우 유발하나 → 승자 배증
16. 꾸준한 리듬 (Pinterest는 지속가능한 페이스가 volume보다 중요)
```

## Part 4 — 콜드스타트 실행 순서 (팔로워 0 현실 반영)

```
지금 (즉시):
  ① Pinterest 수동 게시 시작 — 검색 기반이라 팔로워 0에서도 노출됨
     └ SEO 최적화된 카드 + 키워드 캡션으로
  ② 지속가능한 리듬 (주 몇 개, 꾸준히 — Pinterest는 에버그린이라 복리)

Pinterest 승인 후:
  ③ 자동 게시 + Pinterest Analytics로 저장·클릭 측정
  ④ 측정 데이터로 승자 토픽·훅 배증

Pinterest 검증 후:
  ⑤ 통한 콘텐츠를 Instagram(4:5·DM공유)으로 확장
  ⑥ Instagram은 팔로워 쌓이며 가속
```

**핵심: 팔로워 없이 성장하려면 Pinterest 검색 최적화가 답. Instagram은 그 다음.**
