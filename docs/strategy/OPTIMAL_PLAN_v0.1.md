## 1. 왜 이 조합인가 — 근거 분석

### 1-1. 버티컬: 테무/알리 + 여행지 교차

두 버티컬은 **약점을 서로 보완**한다.

| 항목 | 테무/알리 단독 | 여행지 단독 | 교차 운영 |
|------|-------------|-----------|---------|
| 수익 속도 | 빠름 (즉시 구매) | 느림 (예약까지 시간) | **빠름 유지** |
| 콘텐츠 수명 | 짧음 (품절/단종) | 길음 (여행지 불변) | **장기 SEO 확보** |
| 팔로워 성장 | 폭발적 | 완만 | **폭발 + 유지** |
| 신뢰도 | 낮음 (중국 제품 편견) | 높음 | **균형** |
| 알고리즘 | 트렌디 | 에버그린 | **트렌드 + 축적** |

**핵심**: 테무/알리가 팔로워를 빠르게 모으고, 여행지가 장기 SEO 트래픽을 쌓는다.
두 버티컬을 하나의 채널 컨셉 **"전 세계 숨은 발견"** 으로 묶으면 자연스럽다.

```
채널 컨셉: "세상에 이런 게 있어?"
  → 신기한 제품 발견 (테무/알리)
  → 아무도 모르는 여행지 발견 (여행)
  공통 정서: 호기심 + 발견의 기쁨
```

### 1-2. 언어: 영어 단일

| 기준 | 한국어 | 영어 | 판단 |
|------|--------|------|------|
| 잠재 도달 | 5천만 (한국) | 20억+ (영어권) | 영어 압승 |
| 경쟁 강도 | 낮음 | 높음 | 한국어 유리 |
| 어필리에이트 수익 | 낮음 (한국 CPC) | 높음 (글로벌 CPC) | 영어 압승 |
| 기존 채널 차별화 | 겹침 (유튜브 한국어) | 완전 분리 | 영어 필요 |
| 자동화 품질 | LLM 한국어 우수 | LLM 영어 최우수 | 영어 유리 |

**결론**: 기존 YouTube 채널(한국어)과 완전 분리된 글로벌 채널 구축.
영어로 하면 Temu/Ali 제품도 글로벌 바이어를 타겟할 수 있어 어필리에이트 수익이 훨씬 크다.

### 1-3. 플랫폼 순서: Pinterest → Instagram → TikTok

```
Pinterest 먼저인 이유 4가지:

① 핀 수명 = 6개월~2년
   Instagram/TikTok 포스트 수명 24~48시간 vs Pinterest 핀은 몇 년간 계속 클릭됨
   → 초기 100개 핀이 1년 뒤 월 $500+ 수동 수익 기반

② 직접 어필리에이트 링크 허용
   Pinterest는 핀에 직접 외부 링크 삽입 가능
   Instagram/TikTok은 "링크 인 바이오" 1개만 → 전환 손실 발생
   → Pinterest = 클릭 → 구매 최단 경로

③ API 가장 단순 (개발 난이도 ★★)
   TikTok API 승인: 2~4주 + 복잡한 심사
   Instagram API: 비즈니스 계정 + 앱 심사 필요
   Pinterest API: 개발자 계정 생성 후 즉시 사용 가능

④ 여행 + 제품 둘 다 최강 카테고리
   Pinterest 상위 10개 카테고리: 여행 1위, 홈 인테리어, 패션, 음식
   제품 발견 용도로 사용하는 유저 78% → 구매 의도 높음
```

```
Instagram 두 번째인 이유:
① Pinterest 콘텐츠 그대로 재활용 가능 (이미지 동일)
② 캐러셀 포맷 = 저장율 최강 플랫폼
③ 팔로워 성장 속도 Pinterest 대비 빠름

TikTok 세 번째인 이유:
① API 승인 절차 가장 복잡
② Pinterest → Instagram으로 콘텐츠 검증 후 진입
③ 제품 바이럴 효과 검증되면 TikTok Shop 연동 가능
```

### 1-4. 계정 구조: 단일 통합 계정

| 구조 | 버티컬별 별도 계정 | 통합 단일 계정 |
|------|-----------------|-------------|
| 팔로워 분산 | 분산 (성장 느림) | 집중 (성장 빠름) |
| 브랜드 인지도 | 약함 | 강함 |
| 관리 복잡도 | 높음 (계정 2배) | 낮음 |
| 알고리즘 신호 | 약함 (각 계정) | 강함 (집중) |
| 크로스셀링 | 불가 | 가능 |

**결론**: 통합 계정으로 시작. 팔로워 10만 이상 달성 후 버티컬별 분리 검토.

## 2. 채널 컨셉 확정 제안

```
채널명 후보:
  "HiddenFinds"   — 숨은 발견 (제품 + 여행 통합)
  "WorldUnboxed"  — 세상을 언박싱
  "FindsDaily"    — 매일 새로운 발견

포스팅 리듬:
  월/수/금 → 테무/알리 가성비 아이템 (7~8장 캐러셀)
  화/목/토 → 숨은 여행지 (6~8장 캐러셀)
  일요일   → 주간 베스트 or 시즌 특집

카드 1장 크기: 1080×1080 (Instagram 정사각형 = Pinterest 최적)
카드 수: 최소 5장 ~ 최대 10장
```

## 3. 카드 구성 공식 (호기심 → 저장 → 클릭)

### 테무/알리 버티컬 (7장 예시)

```
Slide 1 [HOOK]
  배경: 충격적인 제품 사진
  텍스트: "7 THINGS on Temu under $3 that
          EVERYONE needs 🤯"
  심리: "뭔데? 넘겨봐야 알겠다"

Slide 2 [TEASE]
  텍스트: "These went VIRAL for a reason.
          Last one is my favorite 👇"
  심리: "마지막 거 궁금해서 끝까지 봄"

Slide 3~6 [REVEAL x4]
  제품 이미지 + 이름 + 가격 + 한줄 설명
  "Why it's worth it: ___"
  심리: 하나씩 점진 공개 = 체류시간 ↑

Slide 7 [CTA]
  "Saved this post? 
   Link in bio → get all 7 items now 🛒
   Which one are you buying? Comment below 👇"
  심리: 저장 + 댓글 + 클릭 동시 유도
```

### 여행지 버티컬 (8장 예시)

```
Slide 1 [HOOK]
  배경: 숨막히는 여행지 사진 (Pollinations AI)
  텍스트: "5 SECRET beaches in Europe
          NOT on Google Maps 🗺️"
  심리: "진짜? 어디야?"

Slide 2 [CREDIBILITY]
  텍스트: "Most tourists miss these because
          they're hidden in plain sight 🙈"
  심리: "나는 달라, 특별한 정보 얻는다"

Slide 3~7 [REVEAL x5]
  여행지 이미지 + 이름 + 국가
  "Best time: ___ | Budget: $___/day"
  "Book a stay → [링크]"
  심리: 버킷리스트 추가 = 저장 유발

Slide 8 [CTA]
  "SAVE this for your next trip 💾
   Which one is on your bucket list?
   Link in bio → Book now at best price ✈️"
  심리: 저장 + 댓글 + Booking.com 클릭
```

## 4. 수익화 구조 (전체)

```
[콘텐츠 포스팅]
    ↓
[Pinterest 핀] ──────────────→ 핀 내 직접 어필리에이트 링크
    ↓                              (클릭 → 구매 = 수수료)
[Instagram 캐러셀]
    ↓
[바이오 Linktree (무료)]
    ├── 이번 주 테무 추천 모음  → Temu Affiliate (3~20%)
    ├── 여행지 예약            → Booking.com (4~8%)
    ├── 여행 액티비티          → Klook / GetYourGuide (5~8%)
```
