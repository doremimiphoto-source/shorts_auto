## 3. 콘텐츠 포맷: 멀티 카드 캐러셀

### 3-1. 왜 멀티 카드가 저장/공유에 최강인가

```
[바이럴 메커니즘]

Slide 1: HOOK — 충격/궁금증 유발 ("이거 모르면 손해")
    ↓ "다음 슬라이드가 궁금해서" 계속 넘김
Slide 2~N: REVEAL — 정보를 한 장씩 점진적 공개
    ↓ 가치 있는 정보 = "나중에 다시 보려고" 저장
Last Slide: CTA — "저장하고 나중에 봐" + 프로필 링크
    ↓ 링크 클릭 → 어필리에이트 전환
```

**Instagram 캐러셀**: 단일 이미지 대비 저장율 3~5배, 도달 1.4배
**TikTok 슬라이드쇼**: 2024년 추가 기능, 이미지 시리즈로 업로드 가능
**Pinterest 아이디어 핀**: 멀티 페이지, 외부 링크 허용

### 3-2. 카드 구성 템플릿

| 슬라이드 | 역할 | 내용 | 심리 훅 |
|---------|------|------|---------|
| 1 | **HOOK** | 충격적 숫자/사실/질문 | "다음 장이 궁금해" |
| 2 | **WHY** | 왜 중요한지 1줄 | 관심 유지 |
| 3~N | **REVEAL** | 핵심 정보 1개씩 | 점진적 가치 제공 |
| N+1 | **PROOF** | 증거/수치/사례 | 신뢰 형성 |
| 마지막 | **CTA** | 저장 유도 + 링크 안내 | 행동 유발 |

## 6. 전문가 패널 최종 권고

### 글로벌 바이럴 전략가 A:
> **테무/알리 + 여행지** 조합이 플랫폼별 최적 매칭.
> - TikTok: 테무 제품 (충동 구매 유발, 15초 내 훅)
> - Pinterest: 여행지 (저장 후 2년 뒤에도 클릭 — 장기 수익)
> - Instagram: 둘 다 캐러셀로 동시 운영
>
> **핵심**: 첫 슬라이드에 숫자를 넣어라.
> "이것 5가지" vs "여행지 추천" → 숫자가 있는 쪽 CTR 2.3배.

### 수익화 전문가 B:
> 수익 구조 우선순위:
> 1. **테무 어필리에이트 (최대 20%)** — 저단가지만 전환율이 압도적으로 높음
> 2. **Booking.com (4~8%)** — 예약 1건당 $10~40, 소수 전환으로 의미 있음
> 3. **Linktree Pro (무료 플랜)** → 멀티 링크로 플랫폼별 단일 URL 관리
>
> 초기 3개월: 클릭 데이터 수집 → 전환율 높은 버티컬에 집중 확장.

### K-컬처 마케터 C:
> 테무/알리 + K-뷰티를 분리하지 말고
> **"아시아 직구 꿀팁"** 하나의 채널로 통합 가능.
> 한국 제품 + 중국 제품 + 일본 제품을 묶으면
> 아시아 문화 관심층 전체를 커버 → 팔로워 확장 유리.

### 데이터 분석가 D:
> 자동화 파이프라인 재사용 가능성:
> - **기존 재사용**: Pollinations AI, Pillow 렌더러, Groq/Gemini LLM, 스케줄러
> - **신규 개발 필요**: Instagram Graph API, TikTok Posting API, Pinterest API 연동
> - 개발 우선순위: Pinterest (가장 쉬움) → Instagram → TikTok 순서로 단계적 구현 권장

## 7. 기술 파이프라인 설계 (신규)

### 7-1. 전체 흐름

```
[스케줄러 (launchd)]
    ↓ 하루 N회 실행
[콘텐츠 생성]
    ↓ LLM (Groq/Gemini/Ollama) → 버티컬별 정보 구조화
[어필리에이트 링크 삽입]
    ↓ 제품/여행지 → 어필리에이트 URL 자동 생성
[멀티 카드 렌더링]
    ↓ Pillow card_renderer (N장 슬라이드) + Pollinations AI 배경
[플랫폼별 업로드]
    ├── Pinterest API v5 → 아이디어 핀 (멀티 이미지)
    ├── Instagram Graph API → 캐러셀 포스트
    └── TikTok Content Posting API → 슬라이드쇼
[수익 추적]
    ↓ 어필리에이트 대시보드 클릭/전환 모니터링
```

### 7-2. 멀티 카드 렌더러 확장 계획

현재 `card_renderer.py`는 1장 생성. 확장 필요 사항:
- `render_carousel(slides: list[SlideData]) → list[Path]`
- 슬라이드 타입: `hook` / `info` / `product` / `cta`
- 각 슬라이드에 어필리에이트 URL을 QR코드 또는 짧은 URL로 삽입
- 마지막 슬라이드: 저장 유도 문구 + 채널 로고

### 7-3. 플랫폼 업로더 (신규 구현)

```python
# 신규 모듈 구조
src/
  uploader/
    pinterest.py    # Pinterest API v5 — 핀 생성 (가장 쉬움, 우선 구현)
    instagram.py    # Meta Graph API — 캐러셀 포스트
    tiktok.py       # TikTok Content Posting API — 슬라이드쇼
```

### 7-4. 업로드 스케줄 (예시)

| 시간 | 플랫폼 | 버티컬 | 카드 수 |
|------|--------|--------|--------|
| 07:00 | Pinterest | 여행지 | 8장 |
| 12:00 | Instagram | 테무/알리 | 7장 |
| 17:00 | TikTok | 테무/알리 | 5장 |
| 20:00 | Instagram | AI 도구 | 6장 |

## 8. 어필리에이트 링크 관리 전략

### 8-1. 링크 구조

```
각 포스트 → Linktree (무료) 단일 URL
    ├── 이번 주 테무 추천 → Temu affiliate link
    ├── 여행지 예약 → Booking.com affiliate
    └── AI 도구 모음 → 각 SaaS affiliate

※ Instagram/TikTok은 바이오 링크 1개만 허용
※ Pinterest는 각 핀에 직접 외부 링크 가능 (가장 유리)
```

### 8-2. 플랫폼별 링크 전략

| 플랫폼 | 링크 위치 | 전략 |
|--------|----------|------|
| Pinterest | 핀에 직접 삽입 | 제품/여행지별 직접 어필리에이트 링크 |
| Instagram | 바이오 Linktree | 마지막 카드에 "프로필 링크 클릭" CTA |
| TikTok | 바이오 링크 | 마지막 슬라이드에 "링크 인 바이오" |

## 9. 호기심 유발 콘텐츠 공식

### 검증된 Hook 패턴 (인플루언서 벤치마크 기반)

```
패턴 1: 숫자 + 충격
"$3짜리인데 Amazon에서 $50에 팔리는 물건 7가지 🤯"

패턴 2: 금지/비밀
"항공사가 절대 알려주지 않는 항공권 싸게 사는 법"

패턴 3: 포모(FOMO)
"지금 모르면 이번 여름 여행 후회함"

패턴 4: 대결 구도
"호텔 vs 에어비앤비: 진짜 뭐가 싸?"

패턴 5: 나만 아는 것
"구글 지도에 없는 발리 숨은 해변 (현지인만 앎)"
```

### 저장 유발 공식
- "나중에 써야지" → 실용 정보 (링크, 방법, 꿀팁)
- "친구한테 보내야지" → 놀라운 사실, 재미있는 발견
- "버킷리스트 추가" → 여행지, 먹거리
- "까먹기 전에" → 한정 시간/재고 있는 것
