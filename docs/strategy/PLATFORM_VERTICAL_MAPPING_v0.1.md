---

## 결론 먼저

```
TikTok    →  테무/알리 아이템 (PRIMARY) + K-뷰티 (SECONDARY)
Pinterest →  숨은 여행지     (PRIMARY) + 테무/알리 (SECONDARY)
Instagram →  K-뷰티/K-라이프 (PRIMARY) + 숨은 여행지 (SECONDARY)
```

각 플랫폼이 가장 잘하는 것에 PRIMARY를 배치했다.
**같은 콘텐츠를 각 플랫폼 포맷에 맞게 변환**하면 제작 비용 최소화.

| **주요 연령** | 18~30대 (Z세대 중심) | 25~44세 (밀레니얼 중심) | 20~35세 (다양) |

### 🎵 TikTok — PRIMARY: 테무/알리 아이템

**왜 TikTok × 테무/알리가 최강인가**

```
#TikTokMadeMeBuyIt 해시태그:
  누적 조회수 100억+ (2024년 기준)
  → 제품 발견 → 즉시 구매 패턴이 TikTok에서만 발생

TikTok Shop (2024년 글로벌 확장):
  슬라이드쇼에 제품 태그 → 앱 내 직접 구매
  → 어필리에이트 링크 없어도 수익화 가능

알고리즘 특성:
  팔로워 0명이어도 콘텐츠가 좋으면 100만 조회 가능
  → 초기 계정에 최강 성장 플랫폼
```

**TikTok × 테무/알리 콘텐츠 공식**

```
슬라이드 1 [HOOK — 0.5초에 시선 잡기]
  텍스트: "7 TEMU things under $3 that went VIRAL 🤯"
  이미지: 가장 충격적인 제품 1개 (클로즈업)

슬라이드 2 [TEASE]
  "These products have 50,000+ reviews.
   I tested all of them. Swipe 👉"

슬라이드 3~7 [PRODUCT REVEAL — 1개씩]
  제품 이미지 + 이름 + 가격 + 한줄 평가
  ⭐⭐⭐⭐⭐ "Bought 3 of these"

슬라이드 8 [CTA]
  "Comment which one you're ordering 👇
   All links in bio 🔗"
```

| 항목 | 세부 |
|------|------|
| 포맷 | 이미지 슬라이드쇼 9:16 (5~8장) |
| 카드 크기 | 1080 × 1920 |
| 주 업로드 | 1일 1~2건 |
| 최적 시간 | 저녁 7~10시 (타겟 시간대) |
| CTA | "Link in bio" → Linktree → 테무 어필리에이트 |
| 어필리에이트 | Temu (3~20%), AliExpress (4~9%) |
| 해시태그 | #TikTokMadeMeBuyIt #TemuFinds #AliExpressFinds |

**TikTok × K-뷰티 (SECONDARY)**

```
슬라이드 1: "Korean girls use THIS instead of expensive serum"
슬라이드 2~5: 제품별 효능 + 가격 + 어필리에이트 링크
슬라이드 6: "Full Korean skincare routine — save this 💾"
```

| 항목 | 세부 |
|------|------|
| 포맷 | 이미지 슬라이드쇼 9:16 (4~6장) |
| 주 업로드 | 주 3건 (테무와 교차) |
| 어필리에이트 | YesStyle (10~15%), Stylevana (8~12%) |
| 해시태그 | #KBeauty #KoreanSkincare #SkincareRoutine |

### 📌 Pinterest — PRIMARY: 숨은 여행지

**왜 Pinterest × 여행지가 최강인가**

```
Pinterest 여행 카테고리:
  월 활성 사용자 4.6억 명 중 여행 관련 검색 45%
  → 여행지 핀의 평균 수명 = 18개월 (TikTok의 540배)
  → 100개 핀 → 12개월 뒤 매달 자동으로 클릭 발생

직접 링크 삽입:
  핀 → Booking.com 어필리에이트 링크 직접 삽입
  → "링크 인 바이오" 없이 바로 전환
  → Instagram/TikTok 대비 전환율 2~3배 높음

SEO 복리 효과:
  "hidden beaches Italy"로 검색 → 내 핀이 노출
  → 검색엔진처럼 쌓일수록 트래픽 증가
```

**Pinterest × 여행지 콘텐츠 공식**

```
핀 1장 구성 (아이디어 핀은 멀티 페이지):

표지 이미지: Pollinations AI 생성 여행지 사진
제목: "5 Secret Islands in Greece Nobody Talks About 🏝️"
설명: SEO 키워드 포함 2~3문장
      "Greece has more than Santorini. 
       These 5 hidden islands have crystal water 
       and NO tourists. Tap for details + booking link."
링크: Booking.com 어필리에이트 (숙박 검색)
보드: "Hidden Travel Gems Europe"
```

**아이디어 핀 (멀티 페이지) 구성**

```
페이지 1 [COVER]: 여행지 분위기 이미지 + 제목
페이지 2~6 [REVEAL]: 장소별 이름/특징/예산/계절
페이지 7 [TIPS]: 현지 꿀팁 3가지
페이지 8 [CTA]: "Save + Book via link below 🔗"
```

| 항목 | 세부 |
|------|------|
| 포맷 | 아이디어 핀 (멀티페이지) + 일반 핀 병행 |
| 카드 크기 | 1000 × 1500 (2:3 비율 Pinterest 최적) |
| 주 업로드 | 1일 2~3핀 (보드별 분산) |
| 최적 시간 | 오후 2~4시, 저녁 8~11시 |
| CTA | 핀에 직접 Booking.com / Klook 어필리에이트 |
| 어필리에이트 | Booking.com (4~8%), Klook (4~5%), GetYourGuide (8%) |
| 보드 구조 | 지역별: Europe / Asia / Americas 분리 |
| 키워드 | "hidden gems [country]", "secret beaches", "off beaten path" |

**Pinterest × 테무/알리 (SECONDARY)**

```
제품 핀 형식:
  이미지: 제품 사진 (깔끔한 배경)
  제목: "This $4 gadget is genius 🤯"
  설명: 제품 설명 + 사용법
  링크: 테무 어필리에이트 (직접 삽입)
  보드: "Amazing Finds Under $10"
```

| 항목 | 세부 |
|------|------|
| 포맷 | 제품 핀 (1장) + 컬렉션 핀 (여러 제품) |
| 주 업로드 | 주 5~7핀 |
| 어필리에이트 | Temu (3~20%), Amazon Associates (4~10%) |
| 보드 | "Best Finds Under $5", "Genius Gadgets" |

## 5. 플랫폼별 콘텐츠 재활용 구조

```
[1회 콘텐츠 생성]
    ↓
[마스터 카드셋 생성] — 1080×1080 정사각형 기준
    ├── TikTok용 변환: 1080×1920 (9:16, 텍스트 크기 확대)
    ├── Pinterest용 변환: 1000×1500 (2:3, 세로 레이아웃)
    └── Instagram용 변환: 1080×1080 (1:1, 원본 그대로)

→ 1개 콘텐츠로 3개 플랫폼 동시 업로드
→ 이미지만 리사이즈, 텍스트/정보는 동일
```

**비율별 텍스트 배치 조정**

| 플랫폼 | 비율 | 텍스트 위치 | 폰트 크기 |
|--------|------|-----------|---------|
| Instagram | 1:1 | 중앙 정렬 | 기준 |
| Pinterest | 2:3 | 상단 이미지 + 하단 텍스트 | 기준 -10% |
| TikTok | 9:16 | 상단 Hook + 하단 CTA | 기준 +20% |

## 6. 수익화 경로 플랫폼별 비교

| 플랫폼 | 링크 방식 | 전환 경로 단계 | 예상 전환율 |
|--------|---------|-------------|----------|
| Pinterest | 핀에 직접 삽입 | 핀 클릭 → 구매 (2단계) | 2~4% |
| TikTok | 바이오 링크 | 슬라이드 → 프로필 → 링크 → 구매 (4단계) | 0.5~1.5% |
| Instagram | 바이오 링크 | 캐러셀 → 프로필 → 링크 → 구매 (4단계) | 0.5~1.5% |

> Pinterest 전환율이 가장 높은 이유: 핀 → 구매 직결 경로
> TikTok 총 수익이 높은 이유: 조회수 폭발로 절대 클릭 수가 많음
