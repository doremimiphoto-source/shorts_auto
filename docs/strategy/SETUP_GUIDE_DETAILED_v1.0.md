   - App name: `HiddenFindsDaily Uploader`

   - Website URL: `https://linktr.ee/HiddenFindsDaily`
4. "Connect" 클릭

### C-3. Meta (Instagram) Graph API (즉시 발급 가능)

**링크**: https://developers.facebook.com

1. https://developers.facebook.com 접속 → "My Apps" → "Create App"
2. Use case: **"Other"** → "Next"
3. App type: **"Business"** → "Next"
4. 앱 정보:
   - App name: `HiddenFindsDaily`
   - App contact email: 본인 이메일
5. "Create app" 클릭
6. 대시보드 → "Add products" → **"Instagram"** → "Set up"
7. 좌측 메뉴 "Instagram" → "API setup with Instagram login" 선택
8. "Generate access token" → Instagram 계정 로그인 → 권한 허용
9. Instagram Business Account ID 확인:
   - https://developers.facebook.com/tools/explorer 접속
   - Graph API Explorer → `GET /me/accounts` 실행
   - 페이지 ID 확인 후 → `GET /{page-id}?fields=instagram_business_account` 실행
   - 반환된 `id` 값 = `INSTAGRAM_BUSINESS_ACCOUNT_ID`
10. Long-lived Token 발급 (터미널):
    ```bash
    curl -X GET "https://graph.facebook.com/oauth/access_token\
    ?grant_type=fb_exchange_token\
    &client_id={META_APP_ID}\
    &client_secret={META_APP_SECRET}\
    &fb_exchange_token={단기토큰}"
    ```
11. 앱 Live 모드 전환:
    - 상단 "In development" 토글 → **"Live"** 전환
12. 저장값:
    - `META_APP_ID`
    - `META_APP_SECRET`
    - `META_ACCESS_TOKEN` (long-lived, 60일 유효)
    - `INSTAGRAM_BUSINESS_ACCOUNT_ID`
