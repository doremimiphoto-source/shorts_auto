# Pinterest × K-뷰티 실행 플레이북 v1.0

@HiddenFindsDaily — Pinterest에 K-뷰티 카드를 올려 AliExpress 어필리에이트로 수익화.
승인 대기 중 **지금 할 수 있는 프로필 세팅** + **승인 후 게시 SOP**를 한 문서에.

---

## A. 지금 세팅 (AliExpress 승인 불필요)

### 1. 프로필
- **프로필 사진**: `output/cards/brand/avatar.jpg`
- **커버/보드 커버**: `output/cards/brand/cover.jpg`
- **이름(Display name)**: `HiddenFindsDaily` 또는 `Hidden Finds — K-Beauty`
- **소개(Bio)** — 아래 중 택1 (키워드 포함, 어필리 공시):

```
Korean skincare finds for glass skin ✨ Daily K-beauty picks & honest
product guides from cult-favorite Korean brands. Affiliate links · #ad
```
```
K-Beauty finds you'll want to save 💧 Best Korean skincare — serums,
sunscreen, toners & more. Honest picks. #ad (affiliate)
```

### 2. 보드 (1개로 집중 — 나중에 세분화)
- **보드 이름**: `Korean Skincare & K-Beauty Finds`
- **보드 설명** (키워드 풍부 = Pinterest 검색 노출):
```
The best Korean skincare and K-beauty products for glass skin — serums,
sunscreens, toners, cleansers and essences from cult-favorite Korean
brands (COSRX, Beauty of Joseon, Anua, Laneige and more). Honest picks,
prices and guides for skincare lovers worldwide.
```
- 섹션(카테고리 세분화)은 **핀 20~30개 쌓인 뒤** (Serums / Sunscreen / Toners …)

### 3. 여행·쇼핑 보드
- **비공개(Secret) 처리** → 프로필이 K-뷰티로 통일 (완료)

---

## B. 승인 후 — AliExpress 링크 생성

1. portals.aliexpress.com 로그인 → **Ad Center / Link Generator**
2. **Tracking ID** 생성 (예: `pinterest`) — 채널별 성과 추적용
3. 링크 만들 대상 URL 준비:
   - 추천: 카드 대표 **브랜드 공식스토어** (예: AliExpress에서 "COSRX Official Store" 검색 → 스토어 URL)
   - 또는 그 제품 검색결과 URL
4. Link Generator에 URL 붙여넣기 → **어필리에이트 추적링크** 생성 (`https://s.click.aliexpress.com/e/_xxxx`)
5. 이 링크를 **핀 destination**에 입력 (⚠️ Linktree·단축 금지, 직접 URL만)

> 팁: 한 핀에 링크 1개 → 카드의 **대표(1번) 브랜드 스토어**로. 여러 브랜드면 가장 유명한 것으로.

---

## C. 게시 SOP (세트 1개 = 핀 1개, 반복)

준비된 세트: `output/cards/v3_kbeauty/export_..._<카테고리>/`

1. **Pinterest 만들기(＋) → 핀 만들기** (PC 브라우저)
2. **`pinterest_slideshow.mp4`** 업로드 (영상 핀, 캐러셀 불필요)
3. **제목**: `pinterest/caption.txt` 첫 줄
4. **설명**: `caption.txt` 본문 (⚠️ `[게시자 참고]` 아래는 제외)
5. **링크**: B에서 만든 AliExpress 어필리 링크
6. **보드**: Korean Skincare & K-Beauty Finds
7. 게시 → (권장) 첫 댓글에 사진 출처(있으면)
8. **다음 날 다음 세트** (sunscreen → toner → cleanser …)

### 페이스
- **하루 1핀 정도, 꾸준히** (Pinterest는 일관성 > 폭발). 준비된 4~8세트로 1~2주 커버.
- 도배(하루 다량) 금지 = 스팸 위험.

---

## D. 측정 (핀 쌓인 뒤)
- Pinterest Analytics에서 **노출·저장·아웃바운드 클릭** 확인
- AliExpress Portals에서 **클릭·주문·커미션** 확인
- 잘 되는 카테고리 = 더 자주. 안 되는 건 줄임.

## E. 수익 업그레이드 경로
- 보드에 콘텐츠 쌓이면 → **YesStyle 재신청**(수수료 10% > AliExpress) → 승인되면 링크 교체
- Pinterest 자동게시 승인되면 → 코드 자동 업로드 전환
