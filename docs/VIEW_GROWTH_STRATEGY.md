# 조회수 성장 전략 — 1만 뷰 목표
**작성일**: 2026-07-03
**대상**: 중학생 공부 Shorts 채널
**근거**: `scripts/fetch_video_stats.py` 실측 분석 (116편)

---

## 현실 인식

```
현재: 중앙 ~340뷰 · 최고 2,385 · 1만 이상 0편
목표 1만 = 중앙의 30배, 최고의 4배
```

Shorts 알고리즘은 **소수 테스트 노출 → 반응(리텐션·참여) 좋으면 파도식 확대**.
1만은 초기 테스트에서 **리텐션·참여가 터져야** 대량 노출로 확대된다.
→ 단일 트릭이 아니라 **리텐션↑ + 승리 주제 + 볼륨**의 결과.

| 특징 | 효과 | 반영 |

### 훅 패턴 — 신호 없음 (철회)
"question 훅 최약"은 **채널 성장 시간 교란**이었음. 최근엔 상위.
→ **훅 선택 로직은 건드리지 않음** (재점검으로 헛다리 회피).

### 썸네일 — Shorts 무관
Shorts 피드는 커스텀 썸네일이 아니라 **영상 첫 프레임** 사용 → 투자 무의미.

### 이 채널 성공/실패 패턴
```
🔝 "이거 몰랐으면 국어 성적 절대 못 올려😱" (416)  호기심갭+충격어
   "성적 떡락? 3일 만에 리듬 찾는 법" (166)        공감슬랭+숫자+긴박
🔻 "중학생 공부법: 학원 vs 인강" (0)              밋밋·호기심 없음
   "5분 만에 영어 에세이 교정하는 법" (0)          니치(에세이)
```
→ **보편적 공부 고통 + 호기심 갭 + 시험 시즌 긴박 = 승리 / 니치·밋밋·설명형 = 패배**

## 실행 전략 (단계별)

### 1단계 — 리텐션 폭발 (최대 레버)
- 첫 3초: 최강 훅 한 줄 + 한국 학생 배경(완료) + 굵은 온스크린 텍스트로 즉시 스크롤 정지
- 완주·루프: 끝에 반전/보상, 끝→처음 자연 연결
- 첫 프레임 = 사실상 썸네일 → 첫 프레임 임팩트 강화

### 2단계 — 주제 전략
- 보편·고통 주제 우선 (성적 떡락·밤샘·집중 안 됨), 니치 지양
- 시험 시즌 캘린더 연동 (중간·기말 2주 전 검색 급증)
- 트렌드·검색어 반영 (현재 모티프 풀 기반, 트렌드 미반영)

### 3단계 — 참여 장치
- 댓글 유발("몇 점인지 댓글") · 공유("이런 친구 태그") · 저장("캡처")

### 4단계 — 측정 연동 ⭐ (진짜 최적화의 열쇠)
```
현재: 조회수만 봄 → 왜 안 터지는지 모름
→ YouTube Analytics API 연동:
   · 리텐션 곡선 (몇 초 이탈?) → 훅 정밀 수정
   · 트래픽 소스 (탐색 vs 검색) → 주제 전략
   · 완주율·참여율 → 데이터 기반 개선
```

### 5단계 — 볼륨·일관성
- 꾸준한 4편/일 (돌파 확률 = 시도 횟수)
